# Model Evaluation Instructions

This project is divided into four parts: **part_1A**, **part_1B**, **part_2A**, and **part_2B**. Each part contains its own evaluation script to assess the performance of the trained models.

## How to Evaluate the Models

For each part, follow these steps:

1. **Navigate to the corresponding directory** for the part you want to evaluate. For example, to evaluate part 1A:

   ```bash
   cd NLU/part_1A
   ```

2. **Run the evaluation script** using Python:
   ```bash
   python eval_models.py
   ```

This process is the same for all parts:

- For **part_1A**:
  ```bash
  cd NLU/part_1A
  python eval_models.py
  ```
